# Agentes

O **Singularity Hub** é o processo local que vai coordenar vários agentes de código, como o OpenCode, e mostrar tudo num único painel.

**Ele ainda não existe nesta versão.** Por isso não há sessões nem botões de agente aqui. Quando houver integração real, este passo será atualizado.

O suporte ao chat e aos agentes do Code - OSS continua presente, e o login em qualquer serviço é sempre opcional.
