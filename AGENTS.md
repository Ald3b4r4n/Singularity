# VS Code Agents Instructions

This file provides instructions for AI coding agents working with the VS Code codebase.

For detailed project overview, architecture, coding guidelines, and validation steps, see the [Copilot Instructions](.github/copilot-instructions.md).

## Singularity IDE

- Desenvolva com EGM e Vibe Coding sem Spec Kit. Use testes proporcionais ao risco e preserve a arquitetura do Code - OSS. Documente patches ao upstream em `UPSTREAM-TOUCHPOINTS.md`.
- Faça um commit por task concluída. Faça push normal, confirme o HEAD remoto e confira a árvore de trabalho.
- Em E2E, valide a janela-alvo e use perfis, diretórios e projetos sintéticos. Preserve os programas e dados pessoais.
- Mantenha tokens, códigos OAuth válidos, perfis privados, caminhos pessoais, capturas de outros programas e conteúdo de projetos privados fora dos artefatos publicados.
- Preserve os avisos de licença e a autoria dos componentes de terceiros. A publicação de binários e releases depende da autorização para o ciclo correspondente.
